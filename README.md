# 🍕 Pizzeria Miracle since 1994

Proyecto desarrollado en **React** como parte del **Hito 1 - Pizzería Mamma Mía**.

El objetivo de este proyecto fue crear la interfaz inicial de una pizzería utilizando React, componentes reutilizables, props y estilos con Bootstrap.

## 📝 Descripción

Se desarrolló una página web para **Pizzeria Miracle since 1994**, donde se muestran diferentes pizzas disponibles junto con su precio, ingredientes e imagen.

La página fue construida utilizando componentes de React para organizar y reutilizar el código.

## 🧩 Componentes creados

El proyecto está dividido en los siguientes componentes:

- **Navbar:** barra de navegación principal de la página.
- **Header:** encabezado principal con imagen de fondo y nombre de la pizzería.
- **Home:** componente encargado de organizar el contenido principal.
- **CardPizza:** componente reutilizable que muestra cada pizza.
- **Footer:** pie de página del sitio.

## 🍕 Pizzas disponibles

Actualmente se muestran tres pizzas:

- Napolitana
- Española
- Pepperoni
